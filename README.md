# My other website
### (another PHP/SQL website that I created, which could be used by another department while setting up laptops)

After creating a website with these languages (which can be seen in [another repo that I have](https://github.com/Jake-beadle/JakeWeb), I created this website which can be used by other employees to set up laptops more easily.

Once again, this website should be somewhat usable if hosted on a webserver, however different SQL databases will have to be used (have removed the previously used connections).
If you create a database and add tables similar to the ones shown in the images, then it should work fine after adding the database to the mysqli_connect lines
